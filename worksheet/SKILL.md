# K-5 Worksheet Maker

Open `index.html`, choose the grade and operation, set the count and seed, then Print → Save as PDF.

- Page 1 is the worksheet; page 2 is the answer key.
- Subtraction never goes below zero; division always divides exactly; multiplication factors scale with the grade.
- Duplicate questions are suppressed.
- **Regenerate** changes the seed. Keep the seed to reprint an identical sheet later.
- **Download JSON** exports the config and every problem with its answer.

Print at 100% / Actual size. No network, no account, no AI model.
